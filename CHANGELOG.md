## [2.0.0] - 2026-10-09

A year of work since v1. The app has a new look, a podcast mode, offline practice and Claude support.

### Before you upgrade

- **Back up your database** (`SQLITE_PATH`). Migrations run automatically on startup and are not reversible. Topics are moved into a tree; duplicate topic names under the same parent make the migration fail, so rename them first.
- **Google login now needs cookie keys.** If `GOOGLE_CLIENT_ID` is set, the server refuses to start without `COOKIE_HASH_KEY` (≥32 bytes, `openssl rand -hex 32`) and `COOKIE_BLOCK_KEY` (`openssl rand -hex 16`). Without login nothing changes.
- **Pin a version.** Images are now published as `ghcr.io/korjavin/german-conjuctions-trainer:2.0.0` (also `:2.0`, `:2`, `:latest`). Use `:2` to get fixes and features without breaking changes.
- Airtable storage is deprecated and will be removed. Use SQLite (the default).

### New

- **New interface.** Today, Practice, Topics, Listen, History and Me pages with a bottom tab bar on mobile. One topic scope is shared by practice and podcasts. Toasts and confirm dialogs replace browser pop-ups.
- **Podcast mode.** Turns a topic into a Glossika-style MP3 episode: listen, then recall. German is spoken slower (`PODCAST_DE_SPEED`). Episodes can contain favorites only. Logged-in users get a private RSS feed for any podcast app (set `PUBLIC_BASE_URL`).
- **Offline practice.** The app installs as a PWA, stashes a batch of exercises and syncs your results when you are back online.
- **Topic tree.** Nested topics with drag-and-drop, search, sorting, keyboard navigation and an Archive for topics you no longer practice.
- **Mistake explanations.** After a session, the AI explains the mistakes you made.
- **Favorites and history.** Star exercises; filter history by due, favorites, trained and topic; see upcoming reviews on a chart.
- **Claude support.** Use Claude through the native API (`LLM_PROVIDER=anthropic`) with prompt caching, and keep a second provider as automatic fallback (`LLM_FALLBACK_*`) for when credits run out. Optional cheap background pre-generation through the Batches API (`LLM_BATCH_MIN_POOL`).
- **Better voice.** ElevenLabs `eleven_v4` by default, a separate voice for English (`ELEVENLABS_ORIGINAL_LANGUAGE_VOICE_ID`), and a size limit for the audio cache (`AUDIO_CACHE_MAX_SIZE_MB`).
- **`gct` command-line client** for managing topics and generating exercises from a terminal or scripts. See [CLI.md](CLI.md).
- **Admin page** with database statistics, prompt version history and the last refined prompt.

### Fixed

- "Database is locked" errors when several requests write at once.
- Spaced-repetition intervals and session statistics were counted wrong in some cases.
- Admin-only endpoints were reachable without admin rights; the audio cache listing and debug endpoints were public.

### Security

- Rate limits on generation, explanations, text-to-speech and podcasts.
- CSRF protection for Google login; session cookies are `Secure` and `SameSite=Lax`.
