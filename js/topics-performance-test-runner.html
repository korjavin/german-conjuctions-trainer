Topic Tree Performance Tests

This page runs performance tests for the topic tree optimizations including:

  • Debouncing for search input
  • Optimized tree building and flattening algorithms
  • Virtual scrolling for large topic lists (> 100 topics)

Note: These tests require the main application to be loaded. Open the main app first, then use the browser console to run these tests, or include this test file in the main application's HTML.

How to Run Tests

Method 1: In Browser Console

  1. Open the main application
  2. Open the browser Developer Tools (F12)
  3. Go to the Console tab
  4. Paste and run the code from topics-performance-test.js

Method 2: As Standalone Page

To run as a standalone page, you need to:

  1. Include the main application's JavaScript files
  2. Include this test file
  3. Run the tests via the console or a button

Open the browser console to see test results in real-time.
